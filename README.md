# Developer Village Portfolio

A responsive developer portfolio built with HTML, CSS, JavaScript, and Three.js. It presents a student developer profile, project cards, an interactive 3D village, a learning roadmap, skills, and contact links.

## Features

- Interactive 3D village
- Project cards and detail modal
- Project progress bars
- Skills and technologies section
- Learning and placement preparation roadmap
- Responsive layout for mobile and desktop

## Folder Structure

- `index.html` - main webpage
- `css/style.css` - styling and responsive layout
- `js/main.js` - project cards and modal interactions
- `js/village3d.js` - Three.js village scene

## Run Locally

Use any static server from the project folder. For example:

```bash
npx serve .
```
[Piyush](https://www.ppiyushk.me/)

Keep internet access enabled because Three.js loads from a CDN.

## Customize

1. Update your name, email, and GitHub profile in `index.html`.
2. Edit project details in `js/main.js`.
3. Replace descriptions, technology tags, progress percentages, and repository URLs with real project information.
4. Add screenshots or deployed links when projects are ready.
5. Test the page on mobile and desktop before publishing.

## Included Projects

- LIVOX - Python, Flask, MySQL
- Image Processing Tool - Python, NumPy

Project descriptions, progress percentages, and repository URLs are starter content. Update them to match your actual work.
